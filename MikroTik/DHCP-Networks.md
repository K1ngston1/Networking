# MikroTik — DHCP Server Networks

## Що таке DHCP Server Networks?

**DHCP Server Networks** — це налаштування, у якому визначаються мережеві параметри, які DHCP Server передає пристроям під час автоматичного отримання IP-адреси.

Простими словами, DHCP Server Networks повідомляє пристроям, яку IP-мережу вони використовують, який шлюз (Gateway) та DNS-сервер потрібно застосовувати.

## Для чого потрібен DHCP Server Networks?

Використовується для:

- Визначення IP-підмережі.
- Встановлення шлюзу за замовчуванням (Gateway).
- Вказування DNS-серверів.
- Визначення маски підмережі.
- Передачі мережевих параметрів клієнтам через DHCP.

## Де знайти DHCP Server Networks у WinBox?

Перейти:

`IP → DHCP Server → Networks`

Тут можна:

- Створити нову мережу.
- Змінити мережеві параметри.
- Переглянути наявні мережі.
- Видалити непотрібні записи.

## Основні параметри

| Параметр | Опис |
|---|---|
| Address | Адреса мережі разом із префіксом. |
| Gateway | IP-адреса маршрутизатора, який буде шлюзом для клієнтів. |
| Netmask | Маска підмережі. |
| DNS Servers | DNS-сервери, які отримають клієнти. |
| Domain | Доменне ім'я, яке передається DHCP-клієнтам. |

## Приклад налаштування

Припустимо, у нас є локальна мережа:

`192.168.1.0/24`

Налаштування DHCP Server Networks:

| Параметр | Значення |
|---|---|
| Address | `192.168.1.0/24` |
| Gateway | `192.168.1.1` |
| Netmask | `255.255.255.0` |
| DNS Servers | `8.8.8.8, 1.1.1.1` |

У цьому випадку пристрої автоматично отримуватимуть IP-адреси з налаштованого DHCP Pool, а також інформацію про шлюз і DNS-сервери.

## Як додати DHCP Network через Terminal?

```bash
/ip dhcp-server network add address=192.168.1.0/24 gateway=192.168.1.1 dns-server=8.8.8.8,1.1.1.1
```
