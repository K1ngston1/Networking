# MikroTik — Оновлення прошивки (RouterOS)

**RouterOS** — операційна система маршрутизатора MikroTik. Її оновлення дозволяє отримувати нові функції, виправлення помилок та покращення безпеки.

## Де оновлювати прошивку?

У WinBox потрібно перейти:

`System → Packages → Check For Updates`

## Інструкція з оновлення

1. Відкрити **WinBox**.
2. Підключитися до маршрутизатора MikroTik.
3. Перейти в меню **System → Packages**.
4. Натиснути **Check For Updates**.
5. Вибрати канал оновлення (**Channel**), зазвичай Stable.
6. Натиснути **Check For Updates**.
7. Якщо доступна нова версія, натиснути **Download & Install**.
8. Дочекатися завантаження та встановлення оновлення.
9. Маршрутизатор автоматично перезавантажиться.

## Як перевірити версію RouterOS?

Перейти:

`System → Resources`

У полі **Version** буде відображена поточна версія RouterOS.

Або через термінал:

```bash
/system resource print
```
