# Що таке Broadcast у мережах?

**Broadcast (широкомовна передача)** — це спосіб передачі даних, коли один пристрій надсилає повідомлення всім пристроям у межах своєї локальної мережі (broadcast domain).

Простими словами, Broadcast — це повідомлення для всіх пристроїв у мережі одночасно.

## Як працює Broadcast?

Наприклад, є локальна мережа:

`192.168.1.0/24`

У ній знаходяться:

- Комп'ютер 1 — `192.168.1.10`
- Комп'ютер 2 — `192.168.1.20`
- Принтер — `192.168.1.30`
- MikroTik — `192.168.1.1`

Broadcast-адреса цієї мережі:

`192.168.1.255`

Якщо комп'ютер надсилає пакет на `192.168.1.255`, його отримують усі пристрої в цьому широкомовному домені.

## Для чого потрібен Broadcast?

Broadcast використовується для:

- Пошуку пристроїв у локальній мережі.
- ARP-запитів для визначення MAC-адреси за IPv4-адресою.
- DHCP-запитів під час отримання IP-адреси.
- Передачі інформації всім пристроям локальної мережі.

## Broadcast у IPv4

У кожній IPv4-підмережі є спеціальна broadcast-адреса.

| Параметр | Значення |
|---|---|
| IP мережі | `192.168.1.0` |
| Маска | `255.255.255.0 (/24)` |
| Перша доступна IP | `192.168.1.1` |
| Остання доступна IP | `192.168.1.254` |
| Broadcast | `192.168.1.255` |

Broadcast-адреса — це адреса, у якій усі біти хостової частини встановлені в `1`.

## Broadcast vs Unicast vs Multicast

| Тип передачі | Опис |
|---|---|
| Unicast | Передача даних від одного пристрою до одного конкретного пристрою. |
| Broadcast | Передача даних від одного пристрою всім пристроям у broadcast domain. |
| Multicast | Передача даних від одного пристрою групі пристроїв, які приєдналися до відповідної групи. |

## Важливо

- Broadcast використовується переважно в локальних IPv4-мережах.
- Маршрутизатори зазвичай не пересилають звичайні локальні broadcast-пакети між різними підмережами.
- Надмірна кількість Broadcast-трафіку може створювати зайве навантаження на мережу.
- У IPv6 немає широкомовної адресації Broadcast — замість неї використовуються Multicast-механізми.

## Висновок

**Broadcast = повідомлення всім пристроям у локальному широкомовному домені.**

Наприклад, для мережі `192.168.1.0/24` broadcast-адреса — `192.168.1.255`.

Якщо пристрій надсилає пакет на цю адресу, його отримують усі пристрої відповідного broadcast domain.
