# MikroTik — IP Address (Адресація)

**IP Address** — це унікальна логічна адреса пристрою в IP-мережі, яка використовується для ідентифікації пристроїв та обміну даними між ними.

У MikroTik IP-адреси налаштовуються через меню:

`IP → Addresses`

## Для чого потрібен IP Address?

IP-адреса дозволяє:

- Ідентифікувати пристрій у мережі.
- Обмінюватися даними з іншими пристроями.
- Забезпечувати доступ до маршрутизатора.
- Організовувати взаємодію між різними мережами.

## Де налаштувати IP Address у WinBox?

Перейти:

`IP → Addresses → +`

Основні параметри:

| Параметр | Опис |
|---|---|
| Address | IP-адреса разом із маскою підмережі. |
| Network | Адреса мережі, визначена на основі IP та маски. |
| Interface | Інтерфейс, до якого прив'язується IP-адреса. |

## Приклад налаштування

Припустимо, потрібно призначити MikroTik IP-адресу:

`192.168.1.1/24`

Параметри:

| Параметр | Значення |
|---|---|
| Address | 192.168.1.1/24 |
| Network | 192.168.1.0 |
| Interface | bridge |

У цьому випадку маршрутизатор матиме адресу `192.168.1.1` у локальній мережі `192.168.1.0/24`.

## Що означає /24?

`/24` — це префікс мережі, який відповідає масці підмережі:

`255.255.255.0`

Для мережі `192.168.1.0/24`:

- Адреса мережі: `192.168.1.0`
- Доступні адреси хостів: `192.168.1.1 – 192.168.1.254`
- Broadcast: `192.168.1.255`
- Загальна кількість адрес: `256`
- Кількість доступних адрес хостів: `254`

## Як призначити IP-адресу через Terminal?

```bash
/ip address add address=192.168.1.1/24 interface=bridge
```
Дефолтна ip address для MikroTik 192.168.88.1/24
