# MikroTik — DNS (Domain Name System)

**DNS (Domain Name System)** — це система доменних імен, яка перетворює доменні назви сайтів на IP-адреси.

Простими словами, DNS дозволяє відкривати сайти за їхніми назвами, наприклад `google.com`, замість того щоб запам'ятовувати IP-адреси серверів.

## Для чого потрібен DNS?

DNS використовується для:

- Перетворення доменних імен на IP-адреси.
- Забезпечення доступу до сайтів за їхніми назвами.
- Пошуку серверів та мережевих ресурсів.
- Спрощення роботи з мережевими адресами.

## Як працює DNS?

Наприклад, користувач хоче відкрити сайт:

`google.com`

Процес роботи DNS:

1. Користувач вводить `google.com` у браузері.
2. Комп'ютер надсилає DNS-запит до DNS-сервера.
3. DNS-сервер шукає відповідну IP-адресу.
4. DNS-сервер повертає IP-адресу.
5. Браузер використовує отриману IP-адресу для підключення до сайту.

## Де знайти DNS у WinBox?

Перейти:

`IP → DNS`

Тут можна:

- Вказати DNS-сервери.
- Переглянути налаштування DNS.
- Увімкнути DNS Cache.
- Дозволити або заборонити DNS-запити від клієнтів локальної мережі.

## Основні параметри DNS

| Параметр | Опис |
|---|---|
| Servers | IP-адреси DNS-серверів. |
| Dynamic Servers | DNS-сервери, отримані автоматично від провайдера або DHCP Server. |
| Allow Remote Requests | Дозволяє клієнтам використовувати MikroTik як DNS-сервер. |
| Cache Size | Розмір пам'яті, виділеної для DNS-кешу. |
| Cache Used | Обсяг кешу, який зараз використовується. |

## Приклад налаштування DNS

Можна використовувати публічні DNS-сервери:

| DNS-сервер | IP-адреса |
|---|---|
| Google DNS | `8.8.8.8` |
| Google DNS | `8.8.4.4` |
| Cloudflare DNS | `1.1.1.1` |
| Cloudflare DNS | `1.0.0.1` |

### Як налаштувати DNS через WinBox?

1. Відкрити **WinBox**.
2. Підключитися до MikroTik.
3. Перейти в `IP → DNS`.
4. У полі **Servers** ввести:

`8.8.8.8, 1.1.1.1`

5. За потреби увімкнути **Allow Remote Requests**.
6. Натиснути **Apply → OK**.

## Як налаштувати DNS через Terminal?

Встановити DNS-сервери:

```bash
/ip dns set servers=8.8.8.8,1.1.1.1
```
