# MikroTik — Що таке IP Pool?

**IP Pool (пул IP-адрес)** — це діапазон IP-адрес, який MikroTik використовує для автоматичного призначення адрес мережевим пристроям.

Простими словами, IP Pool — це список доступних IP-адрес, з якого MikroTik може видавати адреси комп'ютерам, телефонам та іншим пристроям.

## Для чого потрібен IP Pool?

IP Pool використовується для:

- Автоматичного призначення IP-адрес пристроям.
- Налаштування DHCP Server.
- Визначення діапазону доступних IP-адрес.
- Керування адресами в локальній мережі.

## Як працює IP Pool?

Наприклад, є локальна мережа:

`192.168.1.0/24`

Створимо діапазон IP-адрес:

`192.168.1.10-192.168.1.100`

Коли пристрій підключається до мережі та надсилає DHCP-запит, DHCP Server може видати йому одну з вільних IP-адрес цього діапазону.

Приклад:

| Пристрій | Отримана IP-адреса |
|---|---|
| Комп'ютер 1 | `192.168.1.10` |
| Комп'ютер 2 | `192.168.1.11` |
| Телефон | `192.168.1.12` |
| Ноутбук | `192.168.1.13` |

## Де знайти IP Pool у WinBox?

Перейти:

`IP → Pool`

Тут можна:

- Створити новий IP Pool.
- Змінити діапазон IP-адрес.
- Переглянути наявні пули.
- Видалити непотрібний пул.

## Як створити IP Pool?

1. Відкрити **WinBox**.
2. Перейти в `IP → Pool`.
3. Натиснути `+`.
4. Заповнити параметри:

| Параметр | Значення |
|---|---|
| Name | `dhcp_pool1` |
| Addresses | `192.168.1.10-192.168.1.100` |

5. Натиснути **Apply → OK**.

## Як створити IP Pool через Terminal?

```bash
/ip pool add name=dhcp_pool1 ranges=192.168.1.10-192.168.1.100
```
