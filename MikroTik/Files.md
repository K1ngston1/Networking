# MikroTik — Ручне оновлення RouterOS через Files → Upload

## Що таке Files → Upload?

**Files → Upload** — функція WinBox, яка дозволяє завантажити файл прошивки RouterOS безпосередньо на маршрутизатор MikroTik.

## Інструкція з оновлення

1. Відкрити **WinBox**.
2. Підключитися до MikroTik.
3. Завантажити потрібну версію RouterOS з офіційного сайту MikroTik.
4. Вибрати правильну архітектуру пристрою (Architecture).
5. Відкрити меню **Files** у WinBox.
6. Натиснути **Upload**.
7. Вибрати завантажений файл прошивки з розширенням `.npk`.
8. Дочекатися завершення завантаження файлу на MikroTik.
9. Перейти в **System → Reboot**.
10. Дочекатися перезавантаження маршрутизатора.

## Як перевірити версію?

Перейти:

`System → Packages`

Або через термінал:

```bash
/system resource print
```
